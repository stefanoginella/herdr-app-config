# `editor-links`

Notes for agents on the mod in `mods/editor-links/`. The index and what holds for every mod are in `AGENTS.override.md`.

Cmd-click on a file path in a terminal opens it in the tab's `file-editor`, at the line and column it ends with. It is not a clone: a link handler, which Herdr added in 0.1.17. It has no view, only `link.js` (`handleLink()`), and its `mod.json` takes every file link (`"pattern": "."`).

## What is where

- It passes (`"pass"`, to the next handler, then Herdr's own opener) a binary by its name (`BINARY`), anything that isn't a regular file (`test -f`, on the terminal's machine), and a terminal outside any tab. A path on another machine is worked out from the clicked text and the terminal's folder there (`where()`), after `place()` has taken its suffix off; one that starts with `~` passes, since that home isn't known.
- The line and column are Herdr's (`link.line`, `link.column`, since 0.1.18) whenever it gives them: for `:12`, `:12:5`, a range (`:5-12`) and an anchor (`#L42`, `#L5-12`, `#L5-L12`), a range or an anchor giving its first line. Only without them (a `file:` URI, `(12,5)`) does `place()` read them itself. `place()` also gives the text without its suffix, which `where()` needs for a remote path, since Herdr's `link.path` is null there and `link.raw` keeps the suffix. It strips as Herdr's `without_suffix()` (`src/links.rs`) does: a trailing period, then an anchor, then a range, then `:12[:5]` or `(12[,5])`. Herdr's path pattern stops at `(`, so a plain `src/a.rs(12,5)` reaches the handler as `src/a.rs` without its place.
- It asks the editor as `project-search`'s `open()` does: `file-editor.open` with `select` (`{ line, start, end }`, the line 1-based, the column as an offset in it), then focuses the tab's editor or splits one in beside the pane clicked. A request older than `FRESH` (10 s) is dropped by the editor, so this only works on the tab being shown, which is where a click happens.
- Tried by calling `handleLink()` from a throwaway mod on a scratch tab: a folder and a PNG passed, a source file with `:22:5` opened in a new editor pane, named after the file. With 0.1.18, on a scratch tab not shown: a folder and `pic.png#L3` passed, and `src/a.rs#L42.` with Herdr's `line` left a request at line 42 and split an editor in. `place()` and `where()` were tried under `node` against every suffix form, remote paths included. A real Cmd-click on a local path was tried by the owner and works, at a line too (before 0.1.18); a `#L` or range click by hand and a remote path were not tried. Herdr detects links with Ghostty's pattern (`src/links.rs`): a path without a `/` is no link, so the handler is never called for it.
