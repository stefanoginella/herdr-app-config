# Hide names

Notes for agents on the window's hide names mode, and on the three clones made for it: the mods in `mods/tabs-names/`, `mods/pane-names/` and `mods/status-names/`. The index and what holds for every mod are in `AGENTS.override.md`.

A mode of the whole window for a screenshot or a screen share, in which the names around the content are plausible made-up ones ("atlas", "Clients", "Refactor search index", `feat/search-filters`, "studio"). Shared `names.hidden` (`true`, else absent or `false`). `status-names.toggle` turns it on and off (`cmd-shift-h` in `global`, and the palette's "Hide Names / Show Names"); the Usage dialog's toggle, its `h` key and `usage.names` set the same flag. What it changes: the sidebar (`space-folders`), the agents list (`agents-unread`), the tab bar (`tabs-names`), the pane headers (`pane-names`), the status bar (`status-names`) and the Usage dialog (`usage`). What it leaves: the panes' content (terminals, the editor, the diff) and the right panel (`files-actions`, `git-panel`, `project-search`), which are content the owner chose to show.

## What is where

- `alias.js`: the made-up names, a pure function of the kind (`project()`, `folder()`, `title()`, `label()`, `branch()`, `machine()`, `path()`) and the real string as drawn. The same file is in `status-names`, `tabs-names`, `pane-names`, `space-folders`, `agents-unread` and `usage` (a mod imports only from its own folder): keep the copies the same. `alias.test.mjs` in `status-names` tests it under `node --test`, and that every copy is byte for byte the same.
- Started again, the app shows names: `status-names` reads, in a task at its start, the app's process id and start time (`ps` on the `$PPID` of a program it runs, which is the app, called `Herdr`), keeps it in shared `names.boot`, and turns `names.hidden` off when the one kept is another run's. `names.boot` is written only when it changed.

## The three clones

- **Mod `tabs-names`** (`mods/tabs-names/`): a clone of Herdr's `tabs` (from version 0.1.18). The one change: while names are hidden, a tab's label is `alias.label()` of what it would show (a tab's number and a bare program's name stay). The clone began with an empty `localStorage`: which side panel each space showed (`panels`) was Herdr's copy's, and is learned again.
- **Mod `pane-names`** (`mods/pane-names/`): a clone of Herdr's `pane` header (from version 0.1.18). The one change: while names are hidden, the folder is `alias.path()` (the space's real name, found through the pane's tab, picks the segment), and a terminal's name is its program's, or `alias.label()` of a name someone gave the pane, never the terminal's own title. A mod pane's name stays: it is the file shown.
- **Mod `status-names`** (`mods/status-names/`): a clone of Herdr's `workspace-status` (from version 0.1.18). Changes: while names are hidden, `alias.machine()` for another machine and `alias.branch()` for the branch; the key command `toggle` (taken through `nextCommand()`, so by the copy on screen, which this one always is), in the palette through `mod.json`; and the start check above.
- In each of the three clones a changed region is marked with a comment that starts `names:`, so a port at the next Herdr update copies Herdr's new file and puts those regions back.

## Behavior to preserve

- A made-up name is a function of the kind and the real string as drawn (trimmed, lower case), and nothing else: no map, no state, nothing written. That is what makes a project the same in the sidebar, the agents list, the pane header and the Usage dialog. Only `space-folders`' folder names depend on the other folders (`names.folderNames()`: in the order of their ids, each avoiding the names given before it), so two folders never read the same.
- Every mod only reads `names.hidden`, in `render()`. It is set only from a click, a key, a command or a task: setting shared state draws every mod.
- Only what is drawn changes. Ids, the model, the order, sorting, `setAgentOrder`, drag and drop and every comparison (`gitTail()`'s "the name already says it", the agents list's same-label check) use the real names.
- What is deliberately not hidden: the panes' content and the right panel; this computer ("This computer", "This Mac"); `~`, a tab's number, a program's name; `main`, `master`, `develop`, `dev`, `staging`, `production`, `trunk`, `HEAD`, a detached HEAD and a branch's conventional prefix (`feat/`, `fix/`, …); the text in the input of a rename dialog (a folder's, a space's, a tab's); the Copy of a machine's `hc machine login` (what is drawn is made up, what is copied is real).
- Not hidden either, being Herdr's: its notifications (an agent finished, with its space), its menus and dialogs (Go to…, the palette, worktree, Settings, Machines), a peek's title, the welcome screen, and the window's title where the system shows it.
- Tried from a shell, in screenshots with names shown and hidden: the sidebar (folders, spaces with their repo and branch, a machine header), the agents list (priority view), the tab bar, a terminal pane's header and the status bar. Not tried by hand when this was written: `cmd-shift-h` and the palette entry as keys, the Usage dialog with names hidden (its toggle, `h`), a sidebar menu and its tooltips, the rail, a pane someone named, an agent on another machine, sub-agent rows, a stack's button and notification, and the start check across a real restart of the app (its id was read and found the same across mod reloads).
